
# Oasis Infobyte Internship — Python Programming

A collection of Python projects developed as part of the **Oasis Infobyte (OIBSIP) Internship Program**. This repository contains five task-based applications, each maintained in its own folder with source code and supporting resources.

The projects demonstrate practical Python programming concepts, including GUI development, input validation, automation, API integration, and application development.

---

## Projects

| Task | Project | Description |
|---|---|---|
| 01 | **Nova — Voice Assistant** | A desktop voice assistant with text and voice interaction and useful everyday commands. |
| 02 | **BMI Calculator** | A simple desktop application to calculate Body Mass Index and display the corresponding category with input validation. |
| 03 | **SecurePass — Random Password Generator** | A password generator designed to create random passwords. |
| 04 | **Atmos — Weather App** | A weather application/dashboard for displaying weather information. |
| 05 | **RelayChat — Chat Application** | A chat application demonstrating messaging-oriented application development. |

## Getting Started

### Prerequisites

- Python 3.x
- Git
- VS Code or any Python-compatible IDE

### Clone the Repository

```bash
git clone https://github.com/bauxzy/OIBSIP.git
```

### Navigate to the Repository

```bash
cd OIBSIP
```

### Run a Project

For example, to run the BMI Calculator:

```bash
cd Python-Task2-BMICalculator
python main.py
```

For other projects, refer to their respective README files for installation and execution instructions.
